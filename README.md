# 模组介绍

## 中文版

**矿物经验汲取（Mineral XP Siphon）**

还在为经验不够发愁吗？挖矿挖到一堆红石、青金石、钻石，却只能堆在箱子里吃灰？

**矿物经验汲取** 复刻了 MITE 经典玩法——你可以**右键直接吞食矿物**，把它们转化为经验值。矿物原有的合成、酿造、附魔、红石等功能**完全保留**，不影响原版玩法。

### 支持的矿物与经验值

| 矿物 | 经验值 |
|------|--------|
| 红石 | 20 XP |
| 青金石 | 30 XP |
| 下界石英 | 40 XP |
| 绿宝石 | 80 XP |
| 钻石 | 120 XP |
| 紫水晶碎片 | 150 XP |

### 风险与代价

吞食矿物并非没有代价：

- **10% 概率中毒 5 秒**
- **20% 概率反胃 5 秒**
- 持续吞食时，负面效果的**持续时间会叠加**，越吃越难受

### 特性

- 食用时间 12 游戏刻（0.6 秒）
- 矿物原有功能完全保留
- 支持多人游戏
- 完整中文/英文双语支持
- 兼容 Fabric 26.2 系列所有版本

## English Version

**Mineral XP Siphon**

Tired of not having enough XP? Mining all those redstone, lapis lazuli, and diamonds, only to let them pile up in your chests?

**Mineral XP Siphon** recreates the classic MITE gameplay — you can **right-click to directly consume minerals** and convert them into XP. All original mineral functions — crafting, brewing, enchanting, redstone — are **fully preserved** and unaffected.

### Supported Minerals & XP Values

| Mineral | XP |
|---------|-----|
| Redstone | 20 XP |
| Lapis Lazuli | 30 XP |
| Nether Quartz | 40 XP |
| Emerald | 80 XP |
| Diamond | 120 XP |
| Amethyst Shard | 150 XP |

### Risks & Costs

Consuming minerals isn't without its price:

- **10% chance of Poison for 5 seconds**
- **20% chance of Nausea for 5 seconds**
- When consuming repeatedly, the **duration of negative effects stacks**, making it worse each time

### Features

- Consumption time: 12 ticks (0.6 seconds)
- All original mineral functions fully preserved
- Multiplayer support
- Full Chinese / English bilingual support
- Compatible with all Fabric 26.2 series versions
